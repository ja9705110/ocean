# 25 週年主視覺 — 背景素材高解析度重製

## 問題

海報畫布是 **5225 × 2941**，但背景素材 `image-1786375259408.webp` 只有 **1671 × 941**。
素材被放大 **3.13 倍**填滿畫布，中間約 70% 的像素由插值產生，導致水波紋理糊化、
金色光軌失去銳利邊緣、光點暈成團塊。這不是壓縮或輸出設定問題，是素材本身尺寸不足。

## 處理方式

以 Real-ESRGAN (RRDBNet x4) 做超解析度重建，而非插值放大。插值只能在已知像素之間
取中間值，補不出不存在的細節；超解析模型則能重建紋理結構。

推論以 224px 分塊進行，重疊 24px 並以餘弦羽化混合，實測無接縫
（各分塊邊界的欄差 z 值皆在 ±2 以內，未偏離全域分布）。

## 檔案

| 檔案 | 尺寸 | 用途 |
|---|---|---|
| `bg_master_6684x3764.png` | 6684 × 3764 | **母檔**。日後任何尺寸都從這裡出發 |
| `bg_poster_5225x2942.png` | 5225 × 2942 | 直接對應現有海報畫布，可 1:1 置換 |
| `compare_before_after.png` | — | 同區域 1:1 前後對照 |
| `upscale.py` | — | 重建腳本，可重跑或套用到其他素材 |

## 輸出尺寸對照

母檔 6684px 寬。大圖輸出的 dpi 需求隨觀看距離下降：

| 用途 | 觀看距離 | dpi | 可輸出寬度 |
|---|---|---|---|
| 桌上立牌、近距離展板 | < 1 m | 150 | 113 cm |
| 一般舞台背板 | 2–3 m | 100 | 170 cm |
| 大型帆布、掛布 | 5 m+ | 72 | 236 cm |

超過上述範圍時，從**母檔**再放大，而非從原始 1671px 素材。例如 3 m 背板 @100dpi
需 11811px，自母檔放大僅 1.77 倍，遠優於原先的 3.13 倍。

## 重跑方式

```bash
pip install torch pillow numpy scipy
curl -sSL -o RealESRGAN_x4plus.pth \
  https://github.com/xinntao/Real-ESRGAN/releases/download/v0.1.0/RealESRGAN_x4plus.pth
python3 upscale.py <來源圖> <輸出圖> [目標寬度px]
```

4 核 CPU 上處理 1671 × 941 約需 7.5 分鐘。
