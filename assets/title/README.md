# 主視覺標題 流向 → 流嚮

## 材質重建

原稿的金色立體字是逐字處理過的美術字，沒有原始分層檔與字型可用，因此材質是從
海報上的 `向` 反推量測後重建的：

| 量測項目 | 結果 |
|---|---|
| 亮度動態範圍 | P1 = 130、P50 = 188、P99 = 235 |
| 光源方向 | 左上（左上緣 L≈204、右下緣 L≈165） |
| 整體漸層 | 上下 ±8%、左右 ±8% |
| 筆畫結構 | 平頂 + 邊緣倒角，倒角約佔筆畫半寬 1/3 |

明暗主要來自**每一筆畫內部**的倒角，而非整體漸層 — 全域漸層只佔 ±8%，卻有 105 階
的總動態範圍。因此材質以距離變換作為高度場、計算表面法線後打光重建。

字型使用 Noto Serif CJK TC Bold。與原稿字形的最佳疊合度為 **IoU 66.6%**
（已含位移與縮放搜尋），屬同一大類但不同刻本。因此 `流` 也一併重排，
避免一個原字配一個仿製字。

## 字面密度問題

`向` 6 劃、`嚮` 17 劃。在相同字面框內，筆畫粗細只有 `流` 的 **0.72 倍**，
視覺上會塌成一團深色塊。

| 版本 | 字面框 | 筆畫粗細比（對 `流`） | 問題 |
|---|---|---|---|
| `liuxiang_same_box.png` | 605 × 681 | 0.72 | 筆畫過細，與 `流` 不等重 |
| `liuxiang_weight_matched.png` | 877 × 987 | 1.04 | 等重，但下緣達 y≈2080，會撞到「朝暮良辰婚宴會館」 |

兩者都需要調整版面才能收斂，這是字本身結構造成的，不是算繪問題。

## 已知落差

合成材質偏柔、偏蠟質；原稿的切面較硬挺，且筆畫內有不規則的裂紋與稜線。
那些是人工逐字繪製的細節，程序化重建無法等價複製。單獨看可接受，
與原字並排時分辨得出來。
